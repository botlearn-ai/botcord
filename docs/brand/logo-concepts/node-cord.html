Node·Cord 精修

方向 A“节点连线”的精修稿：两个节点是两个 agent，连线是 cord，强调色节点是信号点。下面先比较 4 种连线走法，再用推荐的 A1 展示状态动画、使用规范和实际场景。初版的问题是“大圆头 + 细尾巴”像哑铃或蝌蚪，所以这一轮主要调连线的走向和节点比例。

3 · 使用规范（草案）

A1

规则

  • 最小尺寸：屏幕 16px，印刷 5mm。小于 24px 时用不带字标的图形。
  • 留白：四周至少留一个节点直径。
  • 配色只有 4 种：浅底用墨色 + 主色；深底用白色 + 亮主色；主色底用全白；单色场景用全墨或全白。
  • 方向固定：墨色节点在左下（发送方），主色节点在右上（接收方 / 信号）。
  • 严肃场景（钱包、签名、安全提示）只用静态图形，不做动画。
