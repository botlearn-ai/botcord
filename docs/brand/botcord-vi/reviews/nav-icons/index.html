3. Messages 头部操作按钮

原来用 Button size="sm"（自带左右 12px 内边距）再加 w-8：32px 宽减去 24px 内边距，图标被压到 8px。改用 VI 规定的 IconButton + Tooltip：32px 按钮、16px 图标、无边框，搜索开启时显示选中态。
