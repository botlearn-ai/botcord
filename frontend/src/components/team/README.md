# team/

`TeamSpacesPage.tsx`：`/settings/spaces` 和 `/chats/team` 共用的组织治理页面，包含空间选择、组织创建、邀请与接受、用户退出/移除、个人 Agent 入组申请/审批和组织政策。沿用全站主题、中英文及确认对话框，适配窄屏布局。

`teamMode` 下优先打开已加入的组织，其次为待接受邀请；没有组织时展示创建/加入初始化状态。加入沿用管理员按用户 ID 发起邀请、用户刷新后接受的流程。

选择的空间放在 URL `?space=<id>`，只控制此管理页面；不会把现有聊天或运行中的任务切换成组织上下文。数据加载由 `store/team-space-store.ts` 隔离，页面离开或空间变化时关闭未决确认。接口请求使用已登录用户身份，写操作按后端权限重新校验。

`TeamSpacesPage.test.tsx`：实际页面渲染测试，验证 owner/member/invited 状态及旧空间内容在 URL 切换时隐藏。浏览器实测与后端集成验证不能由静态渲染测试代替。

`TeamWorkspaceSkeleton.tsx`：Team 首次加载、鉴权等待与组织数据请求共用的加载布局，沿用团队页面的容器、标题和间距。

自动刷新仅在页面从后台恢复可见时触发，30 秒内合并重复请求；后台刷新保留当前内容并暂时禁用写操作，失败时清除旧空间数据。窗口 focus（包括 DevTools 焦点切换）不触发刷新。
